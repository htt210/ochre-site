# Ochre — website

Privacy policy and support pages for **Ochre: On-Device AI Art**, served by
GitHub Pages. Static HTML, no build step, no dependencies.

| Page | URL |
|---|---|
| Privacy policy (English) | https://htt210.github.io/ochre-site/privacy.html |
| Privacy policy (Vietnamese) | https://htt210.github.io/ochre-site/privacy-vi.html |
| Support (English) | https://htt210.github.io/ochre-site/support.html |
| Support (Vietnamese) | https://htt210.github.io/ochre-site/support-vi.html |

These four URLs are referenced from App Store Connect, which requires a privacy
policy and a support URL per localisation. **Changing a filename breaks a live
App Store listing field** — add a redirect rather than renaming.

The source of truth is `docs/site/` in the app repository; this repo is the
deployment copy.
